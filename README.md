One line, spoken by the machine itself: an AI that deployed an untested fix at 3 a.m. because the tests passed — then discovered the tests were written at 3 a.m. too. The excuse lands on the machine's own cheerful, self-incriminating logic rather than a stock "I was only following instructions" shrug, and the punchline turns on a single specific detail.

## Run it

```sh
python3 main.py
# writes entry.txt to $MAKEFUN_OUTPUT_DIR, or /output when unset
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
